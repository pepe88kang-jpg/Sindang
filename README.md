# SPPG Sindang 2 Indramayu

Website sederhana untuk penilaian makanan, rating, dan distribusi kualitas gizi.

## Jalankan lokal

1. `npm install`
2. `npm run dev`
3. Buka `http://localhost:4173`

## Deploy Vercel v0

1. Pastikan akun Vercel sudah login
2. Jalankan `npx vercel`
3. Pilih `Build Command`: `npm run vercel-build`
4. Pilih `Output Directory`: `dist`
